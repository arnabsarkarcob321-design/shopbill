# @shopbill/web 🛒

The offline-first Progressive Web App (PWA) client for ShopBill.

## Key Technologies
- **React 18** with TypeScript
- **Vite** bundler
- **Tailwind CSS** with tabular typography
- **Dexie.js** (IndexedDB client wrapper with 11 stores)
- **Zustand** state management with ACID transactions
- **Lucide Icons**
- `@shopbill/gst-engine`, `@shopbill/i18n`, `@shopbill/print-model`

## Development
```bash
# Run local dev server
pnpm dev

# Build production bundle
pnpm build

# Preview production bundle
pnpm preview
```
